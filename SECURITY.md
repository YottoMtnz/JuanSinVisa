# Seguridad / Security

## Español
Si encuentras un problema de seguridad relacionado con los archivos publicados de Juan Sin Visa, evita publicar datos sensibles, credenciales o información privada en un issue público. Describe únicamente la información necesaria para reproducir el problema de forma segura.

## English
If you find a security issue related to the published Juan Sin Visa files, do not post sensitive data, credentials, or private information in a public issue. Share only the information needed to reproduce the problem safely.
