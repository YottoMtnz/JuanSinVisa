# Contribuir / Contributing

## Español

Juan Sin Visa es un proyecto con **todos los derechos reservados**. Este repositorio público acepta principalmente reportes de errores, problemas de compatibilidad y observaciones técnicas.

Antes de abrir un issue:
1. Comprueba si el problema ya fue reportado.
2. Indica si ocurre en la versión web o Windows.
3. Incluye pasos claros para reproducirlo.
4. Añade navegador, versión de Windows o dispositivo cuando sea relevante.
5. Adjunta capturas o video si ayudan a demostrar el problema.

La aceptación de sugerencias, parches o pull requests no implica que se conceda una licencia sobre el proyecto ni sobre sus recursos.

## English

Juan Sin Visa is an **all-rights-reserved** project. This public repository primarily accepts bug reports, compatibility issues, and technical observations.

Before opening an issue:
1. Check whether the problem has already been reported.
2. State whether it affects the web or Windows version.
3. Include clear reproduction steps.
4. Add browser, Windows version, or device information when relevant.
5. Attach screenshots or video when they help demonstrate the issue.

Accepting suggestions, patches, or pull requests does not grant a license to the project or its assets.
